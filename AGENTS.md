## Agent skills

### Issue tracker

Issues, specs, and tasks are local Markdown files under `.kiro/specs/<feature-name>/` (`requirements.md`, `design.md`, `tasks.md`); no GitHub Issues or Linear. See `.kiro/steering/issue-tracker.md`.

### Domain docs

Single-context: one shared `GLOSSARY.md` and `adr/` directory in `.kiro/steering/`, used by both apps. See `.kiro/steering/domain.md`.
